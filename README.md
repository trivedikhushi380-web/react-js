# Bike Collection - React Router

A simple Bike Collection website built with ReactJS and React Router.

## Pages

- `/` - Bike Collection with 15 bikes
- `/about` - About page
- `/contact` - Contact page
- `/service` - Services page

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Technologies

- React
- React Router
- Vite
- CSS

No backend or API is required.
